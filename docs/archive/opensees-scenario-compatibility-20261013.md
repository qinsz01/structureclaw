# OpenSees 规划场景能力审计（2026-10-13）

267 个 OpenSees 规划场景（STD / INT / MM 各 89 个）都能由当前工具链表达、计算和查询。这个结论针对完整、经核对且稳定的一阶线弹性杆系模型；它不等于 267 道 Bench 已编制、已建立标答或已完成模型答题实验。

逐题记录在 [`reproducibility/opensees-scenario-compatibility-20261013.json`](../reproducibility/opensees-scenario-compatibility-20261013.json)。原始题目及模型的全部字段保存在 [`reproducibility/scenario-plan-300-20261013.json`](../reproducibility/scenario-plan-300-20261013.json)。本次核对包含 `spec`、独立属性、边界、加载、交互轮次、输出及分析约定，没有把旧关键词投影作为支持证据。

## 关键辨别

- **独立截面属性需要保真。** 许多题只改变某组构件的 I，或者分别给 A / Iy / Iz / J。可用纯属性截面记录，不应强行套用另一个几何截面。分段材料与截面通过共节点的物理杆件表达，界面不变成铰或支座。对应例子包括 STD-013/014/052/099、INT-003/006/011/026/099、MM-014/052/066/095/099。
- **短臂是弹性构件。** STD-100、INT-100、MM-098/100 等保留实际坐标和有限 EA / EI / GJ。双正交短臂、斜枝及分段柱的全部六自由度由独立虚功积分校核，没有采用无限刚臂代替。
- **释放必须按物理含义区分。** 本规划所需主要是支座转动自由、滚支的指定平移自由，以及轴力杆端的铰接行为。MM-096 的中间横向支点、MM-097 的顶端导向均已作独立解析校核。规划不要求通用梁端释放、P-Delta、墙壳或通用非线性。
- **局部荷载不是等合力替代。** 实际加载区间、点力和点矩控制求解网格分段，保存物理杆件映射。连续梁的材料/截面边界与荷载边界可以不重合。D / L / W / 指定组合分别保留。
- **交叉与连接由端点定义。** 纯桁架的相交不连接与显式中点连接，分别用独立杆能量矩阵校核；混合梁柱—轴力支撑保留梁柱转角及支撑的轴向刚度。

## 证据范围

新增 `test_planned_capability_combinations.py` 有 **12 个参数化测试实例**，使用真实 OpenSees，参考来自独立虚功积分、力法与轴力杆能量矩阵。它们验证能力之间的组合，不是用生产求解器给自己生成参考答案。联同已有网格、坐标和物性回归，共 **82 项通过、0 跳过**；DXF 解析器另外 **3 项通过**。

逐题需求按能力集合形成 138 组。这是需求分类数量，**不表示 138 组都各自运行过**。每题的可兼容判断由原文要求、实际模型协议/执行路径和对应能力证据共同构成；完整模型的稳定性和独立参考仍在编题时审定。

此次发现并修复了一个实际交互缺口：原 `undoModel` 只允许回退整体状态完全匹配的事务，无法完成 **INT-026：撤销先前荷载修改，同时保留后来截面修改**。当前按稳定对象和字段执行逆向合并，无关变更保留，真正冲突明确拒绝。公共状态/交付回归 3 套 50 项通过。

`backend/tests/engineering-scenario-acceptance.mjs` 又经真实工具入口验证了：跨内点矩左/右弯矩 20 / 0 kN·m、任意位置含荷载项挠度、节点转角、节点位移差、控制组合，以及选择性撤销后保留加倍 Iy 并重新求解。对应提交为 `9f88314` 和 `90276c3`，运行 ID 及具体数值收录于审计 JSON。

## 后续编题约定

完整的数值属性、坐标/单位和稳定连接必须随题提供，不能用默认值补齐尚未制作的附录。图片、DXF 与表格仍需制作并盲审；现有来源定位、冲突澄清和字段绑定能力不代表已经识别过这些未来附件。参考答案须独立建立，采样图形极值不得冒充连续场精确极值。

本轮没有修改历史 Bench 输入、标答、论文标签或容差，没有运行付费模型实验。OpenSees 生产求解器未因本轮审计改变；新增的是能力回归及可追溯审计记录。共享交互与查询修复由对应工程服务统一承担。
