### 尚未解决的原生精度限制

最新多工况/组合运行的两项失败均为 W 工况 `y2-0-1` 两端轴力：原生 `0.2618408203125 kN`，独立冻结参考 `0.26185917589359065 kN`，仍超过原绝对容差 `1e-5 kN`。D、L、ULS 的全部端力和反力、所有工况及组合的节点六分量和全局平衡均通过，不能用这些通过项掩盖 W 的失败。MM-089 仍有另两个梁端轴力分量未通过；本轮没有把其误差假称为同一子程序导致。

只读诊断 [pkpm-native-precision-diagnosis-20261013-6a364bdf.json](G:/StructureClaw-All/sclaw_data/work/pkpm-native-precision-diagnosis-20261013-6a364bdf.json) 绑定了该次输入、结果、参考和验收文件哈希。已保存节点位移为两个 float32 值，轴向刚度 `EA/L = 8,652,000 kN/m`。对它们执行 float32 的两个刚度乘积再相减，精确复现原生轴力；即使把这些已经量化的位移改用 double 差分重算，也只得到 `0.26184711896348745 kN`，仍超原容差。因此，简单提高 Python 输出精度或在读回后转 double 不能恢复丢失的信息。

两次精度探针实际读回分别为 `SOV_DOUBLE.OUT = T`，以及 `SOV_DOUBLE.OUT = T` 加 `READDISPDIRECT.OUT = T`；机器记录保存具体开关文本与哈希。不能把提出、写入但未被原生读回为 T 的开关算作已启用，更不能从开关为 T 推断所有中间位移/端力都以双精度储存。匹配到一条 float32 算术路径不证明唯一的厂商子程序；当前已验证的公开读回链尚未提供可以替换它的更高精度原生结果。

该限制与已修复的材料、几何、荷载、工况、转角、反力及来源传递问题分开记录。没有放宽容差，没有覆盖参考，也没有用另一个求解器或自行重算值替换原生结果。
