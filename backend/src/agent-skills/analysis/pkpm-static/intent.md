# PKPM Static Analysis

- `zh`: 当用户明确要求使用 PKPM/SATWE 进行结构静力计算、商业引擎复核、设计验算或结果对比时使用。需要本机安装 PKPM，并通过 General Settings / `settings.json` 的 `pkpm.cyclePath` 或环境变量 `PKPM_CYCLE_PATH` 指向 `JWSCYCLE.exe`。
- `en`: Use when the user explicitly asks for PKPM/SATWE structural static analysis, commercial-engine verification, design checks, or result comparison. Requires a local PKPM installation and `pkpm.cyclePath` in General Settings / `settings.json`, or `PKPM_CYCLE_PATH`, pointing to `JWSCYCLE.exe`.
- `zh`: 已校准无自重、无刚性楼板/刚域、一次加载、无 P-Delta 的线弹性框架路径。显式 E/nu/G 通过原生自定义弹性材料保存并核对，A/I/J 与原生截面读回一致；原模型密度保留，自重关闭时不得偷偷计入。当前完整输出要求竖直柱、水平梁、已校准矩形截面和逐项核对的边界；不适用属性明确拒绝。
- `en`: The calibrated path is a linear elastic bare frame with self-weight, rigid floors/offsets and P-Delta disabled, using one-time loading. Explicit E/nu/G are preserved through verified native elastic materials; A/I/J are checked against native section data. Source density is retained without introducing disabled self-weight. Complete outputs require vertical columns, horizontal beams, calibrated rectangular sections and verified boundaries; unsupported properties are rejected.
- `zh`: 矩形柱的两个正交强轴方向通过原生宽高映射保持。纯数值 `custom` 截面可独立指定 A/Iy/Iz/J，当前剪切面积须满足 Asy=Asz=5A/6；在原生前处理之后编译实际构件弹性属性，求解后逐项回读验证。SDK 中的参考正方形仅供建立拓扑，不是用户物理截面，也不得用于规范几何校核。编译输入、源模型哈希和逐构件属性均保留。
- `en`: Both orthogonal strong-axis directions of rectangular columns are preserved through native width/depth mapping. Pure numeric `custom` sections accept independent A/Iy/Iz/J with Asy=Asz=5A/6. Actual elastic member properties are compiled after native preprocessing and verified after solving. The SDK reference square is a topology carrier, not the user's physical section or code-check geometry. Compiled inputs, source-model hashes and per-member properties are retained.
- `zh`: 固定与三向转动释放柱脚均读取原生证据。铰脚在原生前处理后、求解前将被默认钳制的自由转动刚度编译为零；保留前后输入、哈希及求解阶段记录。平移惩罚残差必须满足冻结容差，自由转角取原生输出，反力由完整有符号端力平衡恢复并标明来源。
- `en`: Fixed and three-rotation pinned bases require native evidence. After preprocessing and before solving, the native numerical floor on requested free rotations is compiled to zero, preserving original/compiled input hashes and phase records. Translation penalty residuals must satisfy frozen tolerances. Free rotations come from native output; reactions are explicitly identified as equilibrium recovery from complete signed end forces.
- `zh`: 已验收算例不代表全部 300 题通过。少数受侧向力框架的微小梁轴力仍有超过冻结容差的原生输出，记录为数值验收未通过，不放宽容差、不用其他求解器覆盖；当前状态见 `docs/commercial-native-chain-20261013.md`。不自动调用软件设计验算或把弹性材料当成已审定规范强度。
- `en`: Accepted cases do not certify all 300 tasks. Some small beam axial forces in laterally loaded frames still exceed frozen numerical tolerances; these remain failed checks without widening tolerance or replacing native values with another solver. See `docs/commercial-native-chain-20261013.md`. Native design checks and code strengths are not implied by elastic material acceptance.
