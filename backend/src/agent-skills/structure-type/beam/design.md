# Design

- 规范校核只在用户明确要求时执行（验算、校核、按规范、code check）；“设计一个梁”按建模、分析、报告处理。/ Code checks run only on an explicit request (验算, 校核, 按规范, code check); "design a beam" means model, analysis and report.
- 设计输入（设计强度、稳定系数、限值、计算长度）不在分析流程中追问；校核缺少输入时报告已完成项和未执行项及所缺输入。/ Design inputs are never asked for during analysis; an incomplete check reports performed items and the checks not performed with their missing inputs.
